# Weerblik.nl

Startstructuur voor het vastleggen van websitebestanden en WeeWX-configuratie.

## Uitgangspunt

Deze openbare repository heet `Sloefke/weerblik-weewx` en heeft als beschrijving
“installatie Weewx”. Bij de inventarisatie op 28 oktober 2026 was de repository
leeg; er waren geen bestanden die de bestaande installatie beschrijven.
De naam Weerblik.nl is de projectnaam voor deze startstructuur, geen uit de
repository aangetoonde koppeling met een live website.

## Mapindeling

| Pad | Bedoeling |

## Status

Alleen documentatie en mappenstructuur zijn aanwezig. Er zijn geen installatie-
of publicatiestappen ingericht. Deze startstructuur wijzigt de live
WeeWX-installatie niet.

**Nog vast te leggen:** WeeWX-versie, installatiepaden, weerstation/driver,
websiteopbouw, hosting, gegevensuitwisseling en publicatiewijze.
Zie de [werknotities](WERKNOTITIES.md).
